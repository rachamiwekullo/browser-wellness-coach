# Daily Wellness Coach

A self-contained browser mini-project inspired by the course's JavaScript
coaching exercise. Enter sleep, water, and step counts to get a transparent
weighted score, a rule-based suggestion, and an in-session history table.

The score is a teaching heuristic—not an AI model, calibrated probability,
medical assessment, or health recommendation. All calculations run locally in
the browser; there is no server and no data is sent or saved.

## Run

Open `index.html` in a modern browser. No build step or dependencies are needed.
